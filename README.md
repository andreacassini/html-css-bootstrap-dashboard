# Bootstrap Dashboard

An admin dashboard layout built with Bootstrap for a course exercise.

**Live demo:** https://andreacassini.github.io/html-css-bootstrap-dashboard/

## What is in it

- Navigation bar and project switcher
- Online students counter
- Upcoming classes table with status badges and a form to add a student

## Run

No build step. Open `index.html` in a browser.
